# How Yellow Books sit next to VR class notes

Two shelves. Do not dump the same chapter twice.

| Shelf | Folder on the site | What it is |
|:---|:---|:---|
| **Class (VR)** | `GS_*_VR_Notes` | What Rizwan / Abhey / Vinay / Tarique dictated. Primary for Ghost Recall of **lectures**. |
| **Yellow Book** | `Yellow_Books` | Full chapter from the institute book, so you can read cover-to-cover here. |

## When a chapter is uploaded

1. **Full chapter** → this folder, one file per chapter (`Concepts_of_Geography/01_…`, `Indian_Geography/03_…`).
2. **Grep class notes first.** Same topic already taught → on the **VR file**, add only a dated `### Update — Yellow Book` with **new facts**. Keep class wording. Do not rewrite the lecture.
3. **No class note yet** → Yellow Book file only. Do not invent a fake lecture in `GS_Geography_VR_Notes`.
4. **Ghost Recall:** one cluster per **new** Yellow Book chapter. Extras on an old class topic patch that cluster’s knowledge graph — **no extra Day-1 row**.

## How you study

- After class: VR note.
- When you read the yellow book: this tab, chapter by chapter. Maps below show **ingested / not uploaded**.
- AWP / test: use the map — if class already covers the micro-topic, VR is enough; Yellow Book is backup for extra lists.
