## 1. Picture of the interior (already in class)

- Layers by depth: crust, mantle, **liquid outer core**, **solid inner core** (iron; magnetic field).
- **Lithosphere:** rigid crust + uppermost mantle = **plates**. Book thickness **7–200 km** (class average **~100 km**).
- **Asthenosphere:** under the lithosphere; hot rock that can **flow**. Book diagram splits it oddly (partially molten 100–200 km, “solid asthenosphere” 200–400 km, transition 400–**670** km). **Class: asthenosphere is semi-solid, often to Repetti ~700 km, entirely inside the upper mantle.** Do not replace class with the book wedge.
- Book radius to centre **6,370 / 6,378 km**; class **6,400 km**. Same order.

## 4. Seismic waves (not in class — learn this)

**Focus / hypocentre** = underground origin. **Epicentre** = surface point **perpendicularly above** the focus. Recorded on a **seismograph / seismometer**.

Waves also from volcanoes, magma, big landslides, explosions.

### Body waves (through the interior)

| | **P (primary)** | **S (secondary)** |
|:---|:---|:---|
| Arrive | **First** | Second |
| Motion | **Longitudinal / compressional** — particles **to-and-fro along** the travel direction (sound-like) | **Transverse / shear** — particles **perpendicular** to travel |
| Medium | Solid, **liquid and gas** (slower in liquid) | **Solid only** — **cannot** cross the outer core |
| Speed | Fastest | Slower than P |
| Interior use | Velocity shifts with elasticity and density | Absence through the core → **liquid outer core** |

### Surface / L waves (along the surface; slower; more damage)

| | **Love** | **Rayleigh** |
|:---|:---|:---|
| Motion | Horizontal **side-to-side**, perpendicular to travel | **Elliptical rolling** (ocean-wave like), vertical + horizontal |
| Speed | Faster of the two surface types | Slightly slower than Love |
| Medium | Near-surface solid | Surface of solids |

**2023 PYQ (book answer (c) both):** (1) seismograph records **P before S**; (2) P = to-and-fro along the path; S = at **right angles**. Both correct.

## 5. Shadow zones (not in class — high-yield)

Book uses **103°** and **105°** on the same page. Treat as **~105°** (NCERT-style), with P-shadow to **142°** (some books **145°**).

| Zone (from epicentre) | What arrives | Meaning |
|:---|:---|:---|
| Within ~**103–105°** | **Both P and S** | Crust + mantle behave as **solid** for S |
| **~105° to 142°** | **Neither** P nor S (shadow for **both**) | P **refracted** at mantle → liquid outer core; S **stopped** by liquid |
| Beyond **142°** | **P returns**; **no S** | P has gone through / around the core; S still blocked → **liquid outer core** |
| Entire far side beyond ~105° | **No direct S** | S-wave shadow is a **whole cap**, not just the 105–142 band |

## 6. Structure — composition vs state (class models stay)

**Suess-style (composition)** — book densities on the disc diagram: SIAL **2.7**; SIMA **2.9–4.7**; NiFe **11**. Class Model 2 used crust **2.7** / mantle **5.4** / core **13**. Different generations of numbers — **do not mix in one MCQ**.

SIAL = granite-ish, silica + aluminium. SIMA = basalt, source of magma. NiFe = nickel + iron.

### Crust (book extras vs GEO-09-09)

Class already: continental granite **2.7**, 60–70 km vs oceanic basalt **3**, 15–20 km; Conrad trap.

| Book extra | |
|:---|:---|
| Share | **0.5–1%** of volume; **less than 1%** of mass |
| Mean density | **2.7 g/cm³** vs whole Earth **5.51** |
| Thickness | Oceanic **5–30 km** (table **~7 km**); continental **50–70 km**, **70–100 km** under Himalaya (class 20 or 70–80) |
| Geothermal gradient | ~**30°C per km**; **200–400°C** at Moho |
| Oceanic age | **Not older than ~200 million years** (created and destroyed) |
| Continental age | ~**4 billion years** |
| P-wave speed | **Higher** in oceanic crust than continental |
| Tectonics | Oceanic thinner → more magma intrusion |

Moho: seismic velocity **jumps**. Oceanic crust subducts; continental more buoyant.

### Lithosphere / asthenosphere / mantle (extras)

- Lithosphere = crust + uppermost **solid** mantle; **plates**; folding and faulting when they move.
- Asthenosphere (*astheno* = weak): book **~80–200 km**; viscous, weak, ductile; **isostatic** adjustment; **magma** source for eruptions. Class depth to ~700 at many places — keep class for placement, book for **isostasy + magma** uses.
- Mantle: Moho → **2,900 km**; ~**83%** volume, **~67%** mass. Upper density **2.9–3.3**; lower **3.3–5.7** (book). Lower mantle **solid** because of pressure (class).
- Mantle mix (book): oxygen **45%**, magnesium **23%**, silicon **21%**, Fe–Mg silicates. T from ~**1,000°C** near crust to ~**4,000°C** at core–mantle boundary → convection.
- **Mesosphere** here = mantle **below** lithosphere + asthenosphere, **above** the outer core (upper boundary ~**660 km**). **Not** the atmospheric mesosphere in Climatology.
- **Barysphere** (diagram) = core.

### Core (extras; class already liquid outer / solid inner at ~6,000°C because pressure)

| | Outer core | Inner core |
|:---|:---|:---|
| Depth (book) | **2,900–5,100 km** (class Lehmann **5,150**) | **5,100 km** to centre |
| State | **Liquid** (not enough pressure to freeze) | **Solid** under crushing pressure |
| Density (book) | **9.9–12.2** g/cm³ | **12.6–13** |
| T (book) | **4,400–6,000°C** | ~**6,000°C** |
| Mix | NiFe + lighter traces | ~**80%** iron + nickel |
| Extra | Convection + **Coriolis** → **dynamo** → magnetic field | Same as class: pressure keeps it solid |

Volume ~**16%**, mass ~**one-third**.

## UPSC Quick Recall

- **S cannot cross liquid** → outer core liquid. **P shadow 105–142°**; **S shadow** the whole far side beyond ~105°.
- Love = **sideways**; Rayleigh = **rolling**. Surface waves = damage.
- Focus **below**; epicentre **above**.
- Mponeng **~4 km**; Kola book **12.2** / class **13.7**.
- Oceanic crust **not older than ~200 million years**; continental ~**4 Ga**.
- **Mesosphere** in this chapter = lower mantle, **not** climatology’s mesosphere.
- Dynamo = outer-core convection + Coriolis.
