# Ghost Recall — interval plan (from 2 September 2026)

> **Goal:** every lecture on an expanding gap. **Constraint:** 8 questions, 60 minutes, one batched paper.
> Method: **spaced repetition + active recall**, but the card is a **lecture cluster**, not 391 micro-topics.

## Why micro-topic Day 1–2–3 cannot cover the bank

| If we quiz… | First-pass load | Fits 8/day? |
|:---|:---|:---|
| 391 micro-topics at Day 1, then 2, 3, 5 | ~370 already “due”; 213 never tested | No. That is the 15–16 question overflow. |
| **26 lectures + CA weeks** at 1 → 3 → 7 → 16 → 35 → 90 | 2 new classes/day + a short catch-up wave | Yes. |

Two classes a day would add ~12–20 **facts**, but only **2 clusters**. Those 2 take the 24-hour slot. The other 6 questions service older gaps.

## Ladder (after a pass)

| Stage after pass | Next gap | Typical prompt |
|:---|:---:|:---|
| New (class day, 5 min self-recite — not Ghost Recall) | **1 day** | 2–3 facts from that lecture |
| +1 passed | **3 days** | Same lecture, different facts |
| +3 passed | **7 days** | Mix + one PYQ trap |
| +7 passed | **16 days** | 1–2 facts or true/false |
| +16 passed | **35 days** | Flash / date / match |
| +35 passed | **90 days** | Flash only |

**Fail:** that **one fact** returns at **+1 day** (atomic). The lecture cluster still moves if most facts were right.

Do not stack Day 2 + Day 5 + Day 10 on the same packet.

## Daily paper (8 questions, all at once)

1. **Q1–Q2** — yesterday’s two classes (24 h). If no class, pull the next catch-up cluster.
2. **Q3–Q6** — two scheduled clusters, two facts each (catch-up first, then 3-day / 7-day repeats).
3. **Q7** — cluster sitting on **+3 or +7** (or +16 once catch-up is done).
4. **Q8** — Mistake Bank if due that morning; else one-line flash on a strong old lecture.
